# Пепел и Вереск

**Тёмная сказка о памяти. Кооператив на 1–4 игроков по WiFi.**

Огонь угасает. Мгла забирает имена, лица и всё, чем ты был. Ты — Искра. Собери три уголька, открой часовню, встреть Плакальщика и реши, кому достанется Сердце Мглы.

Игра написана на чистом JavaScript и Canvas: без фреймворков, без внешних ассетов и без интернета. Вся графика и звук создаются процедурно. Работает в браузере и в Android-обёртке.

## Что внутри

- Полноценная сюжетная глава с прологом, тремя угольками, обрядом трёх имён, побочными историями, боссом и тремя финалами.
- Открытый мир 144×104: Соляная топь, кратер Тихой Звезды, южные курганы и Вересковая мельница. Сюжетную тропу можно оставить и уйти исследовать.
- Три класса: Фонарщик, Охотница и Палач; у каждого своя атака, рывок и способность.
- Боевая система: авто-прицел, удар строго по нажатию, рывок с неуязвимостью, замах врагов, фазы босса, лечение, падения и подъём союзников.
- Осколки падают с врагов. На верстаке у последнего очага покупаются улучшения урона, скорости, дальности и резонанса способности.
- Карта с мини-картой и метками: цель, опасность, добыча и дом. Метки сохраняются для каждого мира и видны в тумане.
- Новые побочные истории: травы Милы, сигнальные огни Гарма, курганы Ады и третий путь Отшельника Каля.
- Кооператив до 4 игроков: хост считает мир, клиенты присылают ввод, состояние синхронизируется снимками.
- Локальная сеть: без интернета, без аккаунтов, без внешних серверов.
- Сохранение в `localStorage` для соло и хоста, включая осколки, прокачку и собранные травы.
- Русский интерфейс, диалоги, процедурная музыка и звуки.
- Сенсорное управление для телефона и клавиатура для браузера.

## Быстрый старт в браузере

Нужен [Bun](https://bun.sh) 1.1+.

```bash
cd ash-and-heather
bun server.js
```

Открой `http://localhost:8080`. В консоли также появится адрес телефона в WiFi-сети.

Порт можно изменить:

```bash
PORT=9000 bun server.js
```

В окружении OpenCode для Android используется обёртка:

```bash
sh scripts/bun.sh server.js
```

## Кооператив по WiFi

1. Один игрок нажимает **«Создать игру»**.
2. В HUD появляется адрес вида `http://192.168.1.42:8080`. Нажми на плашку комнаты, чтобы скопировать адрес.
3. Остальные открывают этот адрес в браузере на телефоне или компьютере в той же WiFi-сети.
4. Нажимают **«Присоединиться»** и входят в туман.

Хост — авторитетный: его игра считает врагов, урон, диалоги и события. Клиенты только отправляют ввод и рисуют полученные снимки мира. Если хост выходит, комната закрывается.

## Android APK

APK собирается из папки `android/`. Внутри — WebView-оболочка, локальный HTTP-сервер на NanoHTTPD и WebSocket-ретранслятор на Java-WebSocket. При запуске приложение само поднимает серверы, поэтому хост-телефон раздаёт игру друзьям по WiFi.

### Сборка через GitHub Actions

В проекте уже есть workflow `.github/workflows/build-apk.yml`.

Готовый debug-APK этой сборки лежит в `dist/ash-and-heather-debug.apk` (папка `dist/` не коммитится в репозиторий).

1. Загрузи **содержимое папки `ash-and-heather`** в корень нового GitHub-репозитория (не родительскую папку с другими проектами).
2. Открой вкладку **Actions** → **Build Android APK** → **Run workflow**.
3. После сборки скачай артефакт `ash-and-heather-debug-apk`.
4. Внутри архива будет `app-debug.apk`. Установи его на телефон (разреши установку из неизвестных источников).

Workflow использует Java 17, Android SDK и Gradle 8.7. Debug-APK подписан автоматически и устанавливается без отдельного keystore.

### Локальная сборка

Нужны JDK 17 и Android SDK 34:

```bash
cd ash-and-heather/android
gradle :app:assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/`.

### Как играть после установки

- Телефон-хост: установи APK и запусти игру.
- Нажми **«Создать игру»**.
- Друзья открывают показанный `http://IP:8080` в браузере. APK им не нужен.
- Если все играют с APK, клиент вводит адрес хоста вручную: `ws://IP-хоста:8080/ws` (игра сама попробует соседний порт ретранслятора).

Порты выбираются автоматически: `8080/8081` → `8090/8091` → `8100/8101` → `8120/8121`.

## Управление

| Действие | Клавиатура | Телефон |
| --- | --- | --- |
| Движение | WASD / стрелки | джойстик слева |
| Удар | Пробел | кнопка с мечом |
| Рывок | Shift | кнопка-молния |
| Способность | Q | кнопка-звезда |
| Говорить / отдыхать / поднимать | E | кнопка-рука |
| Карта и метки | M | кнопка «M» или мини-карта |
| Пауза | Esc | кнопка «II» |
| Выбор в диалоге | 1–4 | нажатие на вариант |

Удар автоматически нацеливается на ближайшего врага. Способности тратят Память; когда Память заканчивается, Мгла подходит ближе. У костра можно восстановить здоровье и Память.

На большой карте выбери тип метки и коснись места. Метка появится в мире столбом света и сохранится в `localStorage` для текущего seed мира. Осколки с врагов тратятся на верстаке у последнего очага: заточка, быстрый взвод, дальний взгляд и резонанс.

---

## Сохранения

Соло и хост сохраняют прогресс в `localStorage` браузера или WebView. «Продолжить» появляется в главном меню после первого сохранения. Клиенты кооператива не сохраняются отдельно: прогресс принадлежит миру хоста.

Очистка данных сайта/приложения удаляет сохранение.

## Тесты

```bash
cd ash-and-heather

# Полный сюжетный путь: диалог, три уголька, часовня, босс, финалы, осколки,
# верстак, травы Милы, третий путь и сохранения
sh scripts/bun.sh tests/flow.mjs

# Доступность NPC, объектов и ворот часовни на нескольких seed-ах
sh scripts/bun.sh tests/map.mjs

# Проверка адресов и кандидатов подключения
sh scripts/bun.sh tests/net-urls.mjs

# Протокол ретранслятора (нужен запущенный server.js)
WS_URL=ws://127.0.0.1:8080/ws sh scripts/bun.sh tests/net.mjs

# DOM/canvas-дымовая проверка соло-режима, карты и верстака
sh scripts/bun.sh tests/dom-smoke.mjs

# Полная проверка хост + клиент (сначала подними сервер)
PORT=8090 sh scripts/bun.sh server.js &
ASH_PORT=8090 SMOKE_MODE=host sh scripts/bun.sh tests/dom-smoke.mjs &
ASH_PORT=8090 SMOKE_MODE=client sh scripts/bun.sh tests/dom-smoke.mjs
```

На обычном компьютере вместо `sh scripts/bun.sh` используй `bun`.

## Ограничения

- Игра рассчитана на одну большую сюжетную главу с открытым исследованием и побочными историями; это законченная вертикальная история, а не бесконечный мир.
- Кооператив работает только в одной локальной сети. Интернет-матчмейкинга и выделенного сервера нет.
- Хост должен оставаться в игре; при его выходе комната закрывается.
- Метки карты хранятся локально и привязаны к seed мира: в чужой комнате они не появятся.
- APK не входит в Git-историю: готовый debug-APK лежит в `dist/ash-and-heather-debug.apk`, а для повторной сборки используй workflow GitHub Actions или локальную команду выше.
